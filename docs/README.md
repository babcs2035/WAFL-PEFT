# docs/ — 設計・調査・執筆物の索引

このディレクトリには，コードからは読み取れない知見（文献調査，実測記録，研究方針の根拠，論文原稿）を置く．
実装の使い方・アーキテクチャの説明は，リポジトリ直下の `README.md` にある．

**命名規約**: 複数ファイルにまたがる機能や横断的な調査は `d0000_TITLE.md` とし，連番は作成順に振る
（`plans/` 側は `p0000_TITLE.md`）．ダウンロード時のままの機械的なファイル名は残さない．
